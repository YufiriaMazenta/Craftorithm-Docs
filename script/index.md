# 脚本引擎概述

Craftorithm 内置了一个编译型脚本引擎，用于触发器的条件判断和动作执行。

## 架构

```
源代码 → 词法分析 (Lexer) → 词元流 (Tokens)
       → 语法分析 (Parser) → AST (抽象语法树)
       → 编译器 (Compiler) → 字节码指令 (Instructions)
       → 虚拟机 (VM) → 执行结果
```

## 数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `Str` | 字符串 | `"hello"` |
| `Num` | 数字 | `100`、`3.14`、`-5` |
| `Bool` | 布尔值 | `true`、`false` |
| `NullValue` | 空值 | — |

## 与触发器的关系

触发器的 `conditions` 和 `actions` 本质上是脚本表达式：

- **conditions**：多个表达式用 `&&` 连接，编译为单个脚本，返回布尔值
- **actions**：多个表达式用换行连接，编译为单个脚本，按顺序执行

## 运行脚本命令

```bash
/cra script <表达式>
```

用于测试脚本表达式，输出执行结果和耗时。

## 注释

脚本支持 `//` 行注释：

```
// 这是注释
level >= 10  // 行尾注释
```
