# 配方书

配方书提供图形化界面，让玩家浏览服务器上的所有 Craftorithm 配方。

## 打开方式

```bash
/cra recipebook [type]
```

不指定类型时打开类型选择界面，指定类型时直接进入对应分类。

## 类型选择界面

显示所有可用配方类型的网格，点击进入对应分类的配方列表。

## 配方列表界面

- **分页浏览**：每页显示固定数量的配方
- **排序模式**：点击排序按钮切换
  - A→Z：按名称升序
  - Z→A：按名称降序
  - 旧→新：按创建时间升序
  - 新→旧：按创建时间降序
- **配方详情**：点击配方图标查看合成方式
- **翻页**：使用上一页/下一页按钮

## 权限

```
craftorithm.command.recipebook
```

## 自定义配方书

可通过自定义菜单系统创建更个性化的配方书。参见 [自定义菜单](/ui/custom-menus)。
