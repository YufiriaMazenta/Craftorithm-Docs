# 世界隔离功能

配方支持设置在哪些世界启用，支持所有的配方类型，但因为实现方式的差异，部分配方类型的表现可能存在一些问题

## 版本差异

### 对于工作台配方（有序、无序）和烧炼配方（熔炉、高炉、烟熏炉、营火）、锻造配方（转换、纹饰）、铁砧配方

开启世界隔离后，该配方在不开启的情况下相当于不存在，因此，它不会干扰相同合成方式的其他配方，可以做到相同的材料在不同的世界合成结果不同的功能

### 对于酿造配方

26.2以下的酿造配方即使在不启用的世界也会开始酿造，但是无法酿造出结果

26.3及以上版本的酿造配方则与工作台配方等配方类型相同

### 对于切石配方

切石配方作为一种特殊的配方类型，它就算设置了在某个世界不可用，依然可以在切石机中看见和选择，但无法实际合成

## 基本语法

```yaml
type: <配方类型>
result: '<物品ID>'
# ... 其他配方字段

enable_worlds: #不设置此项的情况下，配方在所有世界可用
- world
- world_nether
- world_the_end
```
