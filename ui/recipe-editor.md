# 配方编辑器

## 打开方式

```bash
/cra edit <recipe_key>
```

### 示例

```bash
/cra edit craftorithm:my_sword
```

## 编辑功能

1. 打开 GUI，显示当前配方的材料和结果
2. 修改材料或结果
3. 点击保存按钮覆盖原文件
4. 点击删除按钮删除当前正在编辑的配方（需要 `craftorithm.recipe.remove` 权限）

## 保存结果物品全部组件

编辑界面中有一个书本图标，点击可以切换「保存结果物品全部组件」开关，开关默认关闭。

开启后保存修改时，结果物品的全部组件会被完整写入插件内置物品源，不再复用其他物品插件的物品 ID；没有组件数据的原版物品仍然直接使用原版物品 ID。

开关状态不会保存，每次打开界面都从关闭状态开始。

## 注意事项

- 只能编辑 Craftorithm 注册的配方
- 保存后自动重载配方注册
- 原始配方文件被覆盖
- 删除配方会同时移除对应的配方文件，操作不可撤销
- 可选：选择配方书分类
