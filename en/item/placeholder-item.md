# Placeholder Items

A placeholder item represents an item set that contains multiple items (an [Item Tag](tag.md) or an [Item Pack](item-packs.md)).

It is used to indicate that a slot uses an item tag or item pack when creating or editing recipes.

## Usage

Obtain the corresponding item with the command `/craftorithm item getgroupitem itempack/tag <id>`.

Then place it in the recipe creation or recipe editing menu when creating recipes with the GUI.
